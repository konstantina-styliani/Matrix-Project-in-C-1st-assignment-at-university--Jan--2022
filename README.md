# Matrix-Project-in-C-1st-assignment-at-university--Jan--2022
A university programming assignment developed in C during my 1st semester, as part of the Structured Programming course.
The project focuses on creating matrices, defining their dimensions, filling them with values, printing them, and loading matrix data from files.

This repository contains the original 2022 version of the project.
